# Журнал изменений (CHANGELOG)

## [1.0.7] - 2026-09-22
### Добавлено и улучшено
- **Свайп вниз для обновления (Pull-to-Refresh):**
  - Реализован жест обновления экрана (`PullToRefreshBox` Material 3) в списке тем (`DecksScreen`) и на экране детального просмотра темы (`DeckDetailScreen`).
  - При свайпе синхронно обновляются данные базы Room, прогресс кривой Эббингауза, статистика и статус актуальной версии.
- **Интеграция ИИ в редактирование карточек и тем:**
  - На экран детального просмотра темы (`DeckDetailScreen`) добавлен баннер и кнопка вызова генератора новых карточек через ИИ.
  - В диалоге создания/редактирования отдельной карточки (`CardEditDialog`) добавлена кнопка «AI: дополнить ответ и мнемонику»: ИИ автоматически формулирует лаконичный атомарный ответ и яркую ассоциативную мнемонику по введенному вопросу или теме.
  - Диалог редактирования параметров темы (`EditDeckDialog`) приведен к адаптивной сетке кнопок сложности (`Surface` с `Modifier.weight(1f)`).
- **Исправление и оптимизация работы генерации через ИИ:**
  - Полностью переписан `AiCardGeneratorService`: улучшена обработка Google AI Studio Gemini API (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`), OpenRouter, Groq и OpenAI.
  - Автоматическая нормализация опечаток в названиях моделей (например, `gemini-3.6-flash` автоматически мапится в актуальную `gemini-2.5-flash`).
  - Добавлена кнопка «Повторить попытку» при сбоях сети или API.
  - На экран настроек добавлены чипы быстрого выбора моделей и кнопка проверки подключения к AI с моментальным отчетом о статусе.
- **Исправление push-уведомлений:**
  - Добавлены недостающие разрешения `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED` и `FOREGROUND_SERVICE` в `AndroidManifest.xml`.
  - Реализован запуск запроса разрешений Android 13+ и прямой переход в системные настройки при отключенных уведомлениях.
  - Улучшено создание канала уведомлений `ReminderNotificationManager` с приоритетом `IMPORTANCE_HIGH` и мгновенная отправка тестового push-уведомления со всплывающим Toast-подтверждением.
- **Устранение «плавающей» верстки кнопок:**
  - В диалогах создания темы (`CreateDeckDialog`), AI-генерации (`AiCreateDeckDialog`) и редактирования (`EditDeckDialog`) чипы заменены на строго фиксированные, адаптивные сегментированные кнопки `Surface`.

## [1.0.6] - 2026-09-20
### Добавлено и улучшено
- **Сквозная динамическая версионизация:** `UpdateCheckerService` переведен на чтение `BuildConfig.VERSION_NAME` и `BuildConfig.VERSION_CODE`, устранена рассинхронизация с фактической сборкой.
- **Единое сообщение в Telegram:** В пайплайне GitHub Actions отправка уведомления и APK-файла объединена в одно сообщение через `sendDocument` с полным описанием релиза, версией и коммитом.
- **Улучшения раздела «Инструкции»:**
  - Карточки руководства теперь по умолчанию свернуты.
  - Добавлена кнопка переключения «Свернуть/Развернуть все» в верхней панели приложения и быстрый блок управления.
- **Редизайн кнопок оценки («Плохо», «Нормально», «Отлично»):**
  - Исправлена верстка кнопки «Нормально»: увеличен размер шрифта, добавлены выделенные чипы для интервалов («7 ч», «1 дн» и т.д.), предотвращающие наползание текста и смещение строк.
- **Информативный экран завершения сессии (Call-to-Action):**
  - Добавлен блок рекомендаций с понятным объяснением дальнейших действий («Что делать дальше?», статус следующего повторения и подсказки по защите от завала).
### Исправлено
- Настроена постоянная выгрузка текстовых логов сборки (`build-logs`) в артефакты GitHub Actions (`if: always()`) независимо от результата сборки.
- Исправлено завершение шагов отправки и публикации в Telegram в `.github/workflows/release.yml` (добавлен безопасный `exit 0` и `continue-on-error: true`), исключающий падение всего пайплайна при незаданных переменных или сетевых ограничениях.

## [1.0.4] - 2026-09-20
### Добавлено и исправлено
- Исправлено переключение карточек в режиме обучения: устранено залипание первого вопроса, добавлен реактивный `currentCard` с плавной анимацией перехода `AnimatedContent` и автоматическим сбросом скролла при смене карточки.
- Добавлен полноценный раздел «Инструкции» в главное нижнее меню с подробным разбором принципов и механик:
  1. Кривая забывания Германа Эббингауза и активное припоминание (Active Recall).
  2. Кошелек Миллера и лимит рабочей памяти (4–7 единиц).
  3. Правило атомарных карточек («один факт — одна карточка») и составление мнемоник.
  4. Дневной лимит (20 новых карточек в день) для предотвращения выгорания.
  5. Механика защиты от завала (Backlog Defense) при пропуске дней.
  6. Диагностика «тяжелых карточек» (Leech Detection) и рекомендации по их переформулированию.
  7. Пошаговое руководство по проведению ежедневной сессии и честности самооценки.
- Удален блок настройки Telegram-уведомлений из экрана настроек приложения (функционал публикации релизов вынесен строго в CI/CD GitHub Actions).
- Приложение переименовано в Hermann Memo во всех компонентах интерфейса.
### Добавлено и исправлено
- Добавлен автоматический шаг восстановления и генерации `debug.keystore` в CI GitHub Actions для устранения сбоя подписания APK (keystore file not found).
- Включено подробное диагностическое логирование Gradle (`--info`, `--stacktrace`, `--no-daemon`) с перенаправлением логов в файлы `gradle_release.log` и `gradle_debug.log`.
- Добавлена автоматическая выгрузка логов сборки и отчетов (`build-failure-logs`) в артефакты Workflow при любом сбое сборки.
- Добавлена отправка уведомления об ошибке сборки в Telegram.
- Оптимизированы параметры памяти Gradle (`GRADLE_OPTS: -Xmx3g -XX:MaxMetaspaceSize=1g`) для предотвращения падений GitHub Actions runner по нехватке памяти (OOM).

## [1.0.2] - 2026-09-20
### Исправлено
- Устранена ошибка компиляции KSP в GitHub Actions (`ksp.com.intellij.openapi.application.Application.getService is null`), вызванная устаревшим процессором кодогенерации Moshi.
- Удалена неиспользуемая зависимость `moshi.kotlin.codegen` из конфигурации `ksp`.
- В пайплайне GitHub Actions версия JDK обновлена до JDK 21 (Temurin LTS), а шаг настройки переведен на актуальный `actions/setup-java@v5` (устранено предупреждение об устаревании Node.js 20).
- Оптимизированы зависимости проекта: закомментированы неиспользуемые сетевые библиотеки для уменьшения размера APK и ускорения сборки.

## [1.0.0] - 2026-09-19
### Добавлено
- Реализация научно обоснованного алгоритма интервальных повторений на основе кривой забывания Эббингауза.
- Учет кошелька Миллера: лимит 20 новых карточек в день, атомарность карточек («одна карточка — один факт»).
- Адаптивный расчет интервалов по 3 оценкам: «Плохо», «Нормально», «Отлично».
- Механика защиты от лавины долгов (Backlog Defense): порционная выдача (до 35 повторений в день) и блокировка добавления нового материала при наличии накопившихся долгов.
- 10 встроенных демонстрационных колод по ключевым областям знаний:
  1. Английский язык (идиомы и фразовые глаголы)
  2. История России (ключевые даты и вехи)
  3. Основы математики (формулы и аксиомы)
  4. Биология и анатомия человека
  5. География мира и мировые столицы
  6. Программирование и алгоритмы
  7. Физика: фундаментальные законы и константы
  8. Психология и когнитивные искажения
  9. Астрономия и космонавтика
  10. Мировое искусство и шедевры
- Полнофункциональный офлайн-движок на базе Room Database с поддержкой экспорта/импорта.
- Пользовательское создание, редактирование и удаление собственных колод и карточек.
- Модуль проверки обновлений через GitHub Releases с прямым скачиванием APK.
- Интеграция CI/CD GitHub Actions с автоматической отправкой сборки и оповещений в Telegram.
