# Журнал изменений (CHANGELOG)

## [1.0.4] - 2026-09-20
### Добавлено и исправлено
- Исправлено переключение карточек в режиме обучения: устранено залипание первого вопроса, добавлен реактивный `currentCard` с плавной анимацией перехода `AnimatedContent` и автоматическим сбросом скролла при смене карточки.
- Добавлен полноценный раздел «Инструкции» в главное нижнее меню с подробным разбором принципов и механик:
  1. Кривая забывания Германа Эббингауза и активное припоминание (Active Recall).
  2. Кошелек Миллера и лимит рабочей памяти (4–7 единиц).
  3. Правило атомарных карточек («один факт — одна карточка») и составление мнемоник.
  4. Дневной лимит (20 новых карточек в день) для предотвращения выгорания.
  5. Механика защиты от завала (Backlog Defense) при пропуске дней.
  6. Диагностика «тяжелых карточек» (Leech Detection) и рекомендации по их переформулированию.
  7. Пошаговое руководство по проведению ежедневной сессии и честности самооценки.
- Удален блок настройки Telegram-уведомлений из экрана настроек приложения (функционал публикации релизов вынесен строго в CI/CD GitHub Actions).
- Приложение переименовано в Hermann Memo во всех компонентах интерфейса.
### Добавлено и исправлено
- Добавлен автоматический шаг восстановления и генерации `debug.keystore` в CI GitHub Actions для устранения сбоя подписания APK (keystore file not found).
- Включено подробное диагностическое логирование Gradle (`--info`, `--stacktrace`, `--no-daemon`) с перенаправлением логов в файлы `gradle_release.log` и `gradle_debug.log`.
- Добавлена автоматическая выгрузка логов сборки и отчетов (`build-failure-logs`) в артефакты Workflow при любом сбое сборки.
- Добавлена отправка уведомления об ошибке сборки в Telegram.
- Оптимизированы параметры памяти Gradle (`GRADLE_OPTS: -Xmx3g -XX:MaxMetaspaceSize=1g`) для предотвращения падений GitHub Actions runner по нехватке памяти (OOM).

## [1.0.2] - 2026-09-20
### Исправлено
- Устранена ошибка компиляции KSP в GitHub Actions (`ksp.com.intellij.openapi.application.Application.getService is null`), вызванная устаревшим процессором кодогенерации Moshi.
- Удалена неиспользуемая зависимость `moshi.kotlin.codegen` из конфигурации `ksp`.
- В пайплайне GitHub Actions версия JDK обновлена до JDK 21 (Temurin LTS), а шаг настройки переведен на актуальный `actions/setup-java@v5` (устранено предупреждение об устаревании Node.js 20).
- Оптимизированы зависимости проекта: закомментированы неиспользуемые сетевые библиотеки для уменьшения размера APK и ускорения сборки.

## [1.0.1] - 2026-09-19
### Добавлено
- Настроена автоматическая сборка APK на GitHub Actions при каждой синхронизации изменений из Google AI Studio (push в ветки main/master).
- Сгенерирован и включен в репозиторий исполняемый скрипт Gradle Wrapper (`gradlew`).
- Добавлена автоматическая выгрузка скомпилированного APK в артефакты Workflow и отправка готового файла APK в Telegram.

## [1.0.0] - 2026-09-19
### Добавлено
- Реализация научно обоснованного алгоритма интервальных повторений на основе кривой забывания Эббингауза.
- Учет кошелька Миллера: лимит 20 новых карточек в день, атомарность карточек («одна карточка — один факт»).
- Адаптивный расчет интервалов по 3 оценкам: «Плохо», «Нормально», «Отлично».
- Механика защиты от лавины долгов (Backlog Defense): порционная выдача (до 35 повторений в день) и блокировка добавления нового материала при наличии накопившихся долгов.
- 10 встроенных демонстрационных колод по ключевым областям знаний:
  1. Английский язык (идиомы и фразовые глаголы)
  2. История России (ключевые даты и вехи)
  3. Основы математики (формулы и аксиомы)
  4. Биология и анатомия человека
  5. География мира и мировые столицы
  6. Программирование и алгоритмы
  7. Физика: фундаментальные законы и константы
  8. Психология и когнитивные искажения
  9. Астрономия и космонавтика
  10. Мировое искусство и шедевры
- Полнофункциональный офлайн-движок на базе Room Database с поддержкой экспорта/импорта.
- Пользовательское создание, редактирование и удаление собственных колод и карточек.
- Модуль проверки обновлений через GitHub Releases с прямым скачиванием APK.
- Интеграция CI/CD GitHub Actions с автоматической отправкой сборки и оповещений в Telegram.
